# 数据血缘、复现与审计边界

## 收录与未收录

本仓库收录：17张精选历史结果图、最新Top100逐周收益和52周超额等小表、4份与全局周历/换手/Top100直接相关的Python研究脚本快照、详细文档。原始行情、完整因子矩阵、354因子候选全量明细、每期预测Parquet、训练模型、研究员上传的 `barra_cne6.py`、权重表与大量中间结果未收录。这些文件体积大或来源/公开授权未核实。

最新输入数据需包含A股历史日线（开高低收、VWAP、量、金额、复权/公司行为、ST、停牌、涨跌停、上市日期等）、官方 `000905.SH` 指数行情、Alpha360全部定义、Alpha158/GTJA191因子、训练期因子面板、每轮已冻结CNN/XGBoost预测。较早全市场优化还需要 `industry_chg`、`zz500_wgt`、本地CNE6风险实现。逐日历史有效性及发布时间必须由数据提供方确认。

`code/` 是**原研究工程的脚本快照**，可直接核对最新交易数学与文件依赖；不是从GitHub clone后即能零配置重训的独立项目。为了避免发布个人本机路径，数据根目录改为环境变量 `MULTIFACTOR_RAW`；其余脚本仍沿用原研究工程的目录布局（例如 `work/open_factor_v1/output/panels`、`version10_dual_channel_cnn_xgb_global_calendar_fixed/固定模型预测与修正持有期.parquet`）。需要把脚本放回原工程 `work/rolling_v5/`、配置原始数据目录及所需中间文件后再运行。只想检查结果时，读 `results/` 即可。

相关Python包：`numpy`、`pandas`、`scipy`、`matplotlib`、`pyarrow`；原模型训练另需 `xgboost` 和深度学习框架（原训练环境中使用）。这里没有凭空拼一个“可一键训练”命令，因为缺少私有输入与未收录训练脚本。

## 必须保留的限制

1. **354候选事后筛选**：354名单从2021—2025表现反选，XGBoost从其中非Alpha360部分抽96候选。CNN完整Alpha360输入不受这份名单限制，但融合模型仍继承XGBoost通道的前视选择风险；Purge Gap、验证集调参无法消除它。
2. **新增策略是测试期探索**：比较10/15/20/30%档位和Top100/Top200已经观察了2021—2026测试期结果。不能选赢家后把这段再次称为全流程严格样本外。需要另留未看过的时间段或真实前瞻纸面交易验证。
3. **成交与费用简化**：最新Top100脚本按给定开盘价与预先算出的收益处理，缺少完整订单簿、涨跌停排队、冲击成本、借券/融资及现金流税务模型；200多/200空尤其不是可融资券验证的实盘收益。
4. **旧版执行问题**：前期优化版目标行业/风格约束有时成交后越界；第七版严格风险回测曾先看到下一开盘可交易状态再假设同价成交，存在乐观时序。旧周历在跨年有重复信号，原“滚动52行”图已被正式修复版取代。
5. **数据授权与公司行为**：原始数据库、研究员上传文件是否可公开，应由拥有者核实；本仓库没有代替数据许可。个股除权、分红、退市、缺失开盘价格与官方价格指数的经济口径差异需要在实盘前持续审计。
